Editor de escenas

Escribí a la izquierda y mirá a la derecha: la escena se rearma sola mientras tipeás.

El código devuelve la escena con return { ... }. Tab escribe cuatro espacios. Lo que escribís se guarda en este navegador.

Lo que se puede usar
  • Piezas: caja, texto, flecha, tabla, celular, contador, cilindro, camara, y para programas codigo, variable, lista, consola.
  • Todas tienen x, y (el centro), escala, rotacion, opacidad y dentro.
  • La línea: { pieza, a: {...}, dur, curva, en }, { capitulo }, { subtitulo }, { espera }, { marca: 'pregunta', datos: { pregunta, opciones, correcta } }.
  • en: nada (después de lo anterior), un número, '+0.5', '<' (junto con lo anterior), '>'.
  • Curvas: suave, lineal, entrar, salir, pasarse.
  • Colores: fondo, superficie, texto, suave, borde, acento, acento2, exito, alerta, error, papel, marco.
  • Todo está en el README.
