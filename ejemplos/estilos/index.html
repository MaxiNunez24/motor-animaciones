Estilos: la misma escena, otro arte

La escena de abajo no dice cómo se ve: ni colores de verdad, ni fuentes, ni sonidos. Lo pone el estilo, que se cambia con un atributo (estilo="neon") o se importa de un archivo (estilo="./mi-estilo.json"). Probá cada uno, con el sonido prendido.

Cómo se escribe

Con los atajos, la línea de tiempo se lee como lo que pasa (como en Manim):

linea: [
    dibujar('idea'),                                         // el borde se traza y después se rellena
    transformar('idea', figuras.estrella(5, 85), { curva: 'resorte', sonido: 'chispa' }),
    aparecer(['p0', 'p1', 'p2'], { crecer: true }),          // escalonados, si el estilo lo pide
    mover('p1', { y: 400 }),
    sonar('exito'),
]

Un estilo propio

Es un archivo de datos que parte de otro (extiende) y cambia lo que quiera: la paleta, los efectos, las curvas, el escalonado, los sonidos (fabricados con recetas: no hay que bajar nada) y los subtítulos. Este es mi-estilo.json: 

{
    "extiende": "neon",
    "colores": { "fondo": "#0b1020", "acento": "#a3ff12", "acento2": "#ff7a18" },
    "efectos": { "brillo": 0.5, "grano": { "cantidad": 0.05 } },
    "movimiento": {
        "curvas": { "x": { "tipo": "resorte", "rebote": 0.45 }, "escala": "gelatina" },
        "escalonar": { "cada": 0.12, "orden": "azar" }
    },
    "sonidos": {
        "aparecer": "burbuja",
        "paquete": { "burbuja": { "receta": "pop", "agudo": 1400 } }
    },
    "subtitulos": { "modo": "reel", "palabras": 4 }
}

Para que todas las escenas de una página usen el mismo: Motor.usarEstilo('pizarra'). Para un video con ese arte y desenfoque de movimiento: npm run video -- --url ejemplos/estilos/ --estilo reel --desenfoque 8.
